## 📌 Visão Geral

O **Controle de Carteira de Ações** é um aplicativo desenvolvido como trabalho acadêmico para auxiliar investidores no gerenciamento de suas ações. Ele permite registrar compras e vendas, acompanhar a rentabilidade, registrar dividendos e visualizar o desempenho da carteira por meio de dashboards interativos.

---

## 📱 Funcionalidades

✔ **Autenticação de Usuários**  
✔ **Registro de Compras e Vendas de Ações**  
✔ **Histórico de Movimentações**  
✔ **Dashboard de Rentabilidade**  
✔ **Registro de Dividendos**  
✔ **Interface intuitiva e responsiva**

## 📦 Instalação e Configuração

## **🟢 Frontend** 
### **1️⃣ Clonar o repositório**
```bash
git clone https://github.com/Dav1Gomes/ControleCarteiraAcoes.git
cd ControleCarteiraAcoes
```
### **2️⃣ Instalar dependências**
```bash
npm install
```

### **3️⃣ Iniciar o aplicativo**
```bash
npx expo start
```
📱 Escaneie o QR Code com o app Expo Go para rodar no celular.

## **🔴 Backend**
### **1️⃣ Entrar na pasta do backend**
```bash
cd ControleCarteiraAcoes\backend
```
### **2️⃣ Instalar dependências**
```bash
npm install
```
### **3️⃣ Iniciar o servidor**
```bash
node server.js
```

📈 Quando o servidor estiver online, você poderá acessar todas as funções sem problemas.
